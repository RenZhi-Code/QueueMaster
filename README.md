# QueueMaster

A World of Warcraft addon that tracks your queue times with customizable timer bars. Shows how long you've been waiting for dungeons, raids, and battlegrounds with real-time updates and role composition information.

Fully localized in 10 languages - automatically detects your game client language.

Customize colors, fonts, sizes, positions, and more through the configuration panel (`/qm`).

## What It Does

- Shows a timer bar when you join a queue
- Displays how long you've been waiting
- Shows tank/healer/DPS role counts
- Replaces the default Blizzard queue icon
- Lets you customize the appearance and position of bars

## Slash Commands

- `/qm` - Open configuration panel
- `/qmconfig` - Open configuration panel
- `/qmstatus` - Show current queue status
- `/qmtest` - Create a test bar for preview
- `/qm anchor` - Toggle movement anchor
- `/qm debug` - Enable/disable debug mode
- `/qmblizz` - Toggle default Blizzard queue UI
- `/qm reset` - Reset and recreate all queue bars

## Known Issues

- Timer bars sometimes disappear - use "Reset Bars" button in config panel or `/qm reset` command to fix
